# Savvana — Landing Page

Landing page desenvolvida para a **Savvana**, negócio focado em criação de sites, landing pages e campanhas de tráfego pago para empresas e profissionais de serviços.

## Sobre o projeto

O projeto foi desenvolvido com foco em apresentar os serviços da marca de forma clara e profissional, destacar trabalhos realizados e direcionar potenciais clientes para o contato.

A interface foi construída buscando uma experiência moderna, responsiva e objetiva, com atenção à hierarquia visual, navegação e conversão.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Principais características

- Layout responsivo para desktop e dispositivos móveis
- Navegação adaptativa
- Animações e interações
- Seções para apresentação de serviços e projetos
- Chamadas para ação ao longo da página
- Estrutura de SEO e Open Graph
- Foco em performance e experiência do usuário
